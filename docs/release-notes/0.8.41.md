# AI Fabric 0.8.41

## Milvus Metadata Filter Literals

Milvus metadata filters now escape LIKE patterns and string literals as separate
layers. Values such as `PUBLIC_APPROVED` and `SKU_100%` previously produced an
invalid expression because the string parser consumed the wildcard escape.

JSON serialization now encodes the complete already-escaped pattern. Tenant,
deployment, source and publication constraints remain present; rejected portable
filters still fail closed. This corrects provider syntax, not semantic routing,
query interpretation, document ranking or a model-decision fallback.

The fix applies to search and scan, which share the same filter construction.
No schema migration or reindexing is required. Existing stored JSON metadata
remains unchanged. Upgrade the BOM and Milvus adapter to `0.8.41`.

This release includes the verified interactive caller-identity correction from
[0.8.40](0.8.40.md).

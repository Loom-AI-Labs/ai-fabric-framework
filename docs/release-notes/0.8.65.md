# AI Fabric Framework 0.8.65

## Bounded Chain Manager Planning

Chain-directive finalization now uses manager-specific planning instructions
instead of the worker's evidence-summary instructions. Empty completed results
are normal startup state. Structured-output preparation is readiness to plan,
not a domain observation or a reason to end an available investigation.

For this existing directive contract only, server-owned specialist instructions
and output format are placed in the system message. Application input and
grounding remain untrusted data in the user message. Managers select relevant
approved workers within the existing limits and reassess their results.

This is prompt guidance, not a mandatory worker sequence or a minimum worker
count. Completion without workers remains valid when appropriate. Target,
ownership, consent, write policy, schemas, call budgets and bounded output repair
are unchanged. Ordinary specialist finalization keeps its existing prompt path.

## Qualification

The 31-module release-profile build passed: 2,621 tests, zero failures/errors,
three credential-dependent real-provider skips. The ten finalizer tests include
manager prompt-role separation, empty startup, valid completion without workers
and existing bounded correction. Release guards and the minimal Spring Boot
consumer passed. Chain target, authorization and execution-budget tests remain
in the release-profile suite.

The wider Incident Room and Agentic Resolver consumer failures documented in
0.8.64 remain outside this bounded patch; that broader consumer suite was not
rerun or claimed fixed here. Hosted model quality is qualified downstream using
real Support conversations. Publication and live adoption are separate steps,
not implied by local compilation.

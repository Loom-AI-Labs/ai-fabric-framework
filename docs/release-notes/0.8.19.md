# AI Fabric `0.8.19`

- **Release date:** 2026-10-10
- **Maven group:** `io.github.loom-ai-labs`
- **Tag:** `ai-fabric-framework-v0.8.19`
- **Support policy:** latest release only; mixed or parallel framework/runtime versions are unsupported
- **Java:** 21
- **Spring Boot:** 4.1.x

AI Fabric `0.8.19` closes a grounding-scope gap in direct read-action
orchestration. A model could correctly assign a compound obligation to one
vector space while also selecting a grounding-eligible read action whose
reviewed contract belonged to another space. The direct action path previously
executed that action even though the information planner already rejected the
same mismatch.

## Fixed

- A grounding-eligible `READ` action with declared `groundingVectorSpaces`
  executes only when its contract intersects the intent's validated vector
  space.
- A mismatched direct read action is not invoked. The obligation continues as
  information retrieval in the validated intent space under the existing
  deployment allowlist and RAG policy.
- Compound requests can no longer execute the same inventory-style action for
  an unrelated policy/document obligation merely because the model emitted an
  `ACTION` intent.
- Debug metadata records the rejected action, the intent and action grounding
  spaces, and the `RAG_FALLBACK` resolution without exposing provider or source
  credentials.
- Matching read actions, read contracts without an explicit grounding-space
  constraint, and governed write actions preserve their existing behavior.

## Security And Compatibility

The effective vector space remains framework-validated and bounded by
server-owned policy. This release removes action execution authority from a
model-selected action when that action conflicts with the validated evidence
scope. The fallback does not bypass retrieval allowlists, source isolation,
action authorization, confirmation, or tenant/deployment filters.

Applications that relied on a mismatched read action overriding an explicit
intent vector space must correct their action metadata or intent routing. AI
Fabric no longer treats that mismatch as valid action execution.

## Migration

Import the `0.8.19` BOM and upgrade every AI Fabric artifact together. No
database migration, embedding change, or reindex is required. Verify that each
grounding-eligible read action declares the vector spaces its evidence can
satisfy, then run mixed-domain queries in both clause orders.

## Verification

- matching direct read action executes exactly once
- mismatched direct read action executes zero times
- mismatched obligation retrieves only its validated vector space
- compound read action plus RAG evidence remains available to final synthesis
- write confirmation and untyped read-action behavior remain unchanged
- complete core, release-reactor, and real-app gates

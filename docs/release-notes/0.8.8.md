# AI Fabric `0.8.8`

- **Release date:** 2026-10-02
- **Maven group:** `io.github.loom-ai-labs`
- **Tag:** `ai-fabric-framework-v0.8.8`
- **Support policy:** latest release only; mixed or parallel framework/runtime versions are unsupported
- **Java:** 21
- **Spring Boot:** 4.1.x

AI Fabric `0.8.8` preserves structured read-action outcomes when orchestration
uses those outcomes to generate an `INFORMATION_PROVIDED` response.

## Fixed

- Successful read actions used during information orchestration are now retained
  in `data.actions[]` after grounded answer generation.
- Each retained action uses the existing public envelope:
  `action` plus `actionResult`.
- Existing action envelopes are preserved rather than replaced.
- Planner parameters, trusted context parameters, and pinned internal targets are
  not copied into the generated-response projection.
- The projected `ActionResult` continues through the normal response sanitizer,
  including PII handling and configured error-code visibility.

This lets generic clients render structured action output and generated prose
together. The framework does not inspect action names, domain fields, query text,
or generated answer wording.

## Migration

Consumers must upgrade the BOM and all AI Fabric artifacts together to `0.8.8`.
No compatibility mode or parallel old/new runtime is required.

Clients that already read `data.actions[]` for compound/action responses can use
the same envelope for generated information responses. Clients that only render
answer text are unaffected.

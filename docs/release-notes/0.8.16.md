# AI Fabric `0.8.16`

- **Release date:** 2026-10-10
- **Maven group:** `io.github.loom-ai-labs`
- **Tag:** `ai-fabric-framework-v0.8.16`
- **Support policy:** latest release only; mixed or parallel framework/runtime versions are unsupported
- **Java:** 21
- **Spring Boot:** 4.1.x

AI Fabric `0.8.16` hardens compound read synthesis after a live canary found
that correctly retrieved evidence could be omitted from the bounded generation
context.

## Fixed

- Planner-eligible READ actions with declared `groundingVectorSpaces` are now
  exposed only to information intents whose effective vector scope intersects
  the action contract. An inventory read action can no longer consume a
  document-only policy obligation.
- Compound synthesis applies `maxDocumentsUsedForContext` as a true global
  limit, independently from `maxDocumentsReturnedToClient`.
- Context allocation is fair across evidence obligations and selected
  documents. A long first action or document can no longer silently consume
  the complete context budget for its siblings.
- Oversized retrieved documents use bounded, query-relevant excerpts after
  retrieval. This affects prompt packing only; it cannot select a source,
  broaden a vector scope, or bypass access policy.
- `documentsUsed`, per-obligation usage, and top-level used-document counts now
  describe the evidence actually placed in the generation context.
- Compound intent guidance now explicitly forbids copying sibling clauses into
  a child's optimized retrieval query.

## Security And Compatibility

- Vector-space action scoping applies only when both the information intent and
  READ action declare evidence domains. Existing actions without a declaration
  retain their reviewed allowlist behavior.
- `groundingVectorSpaces` remains a constraint, never an access grant. Runtime
  entity validation, deployment allowlists, tenant filters, and source matching
  remain authoritative.
- Excerpt selection occurs only over already approved and sanitized retrieval
  results inside the existing context-character budget.
- Write actions, confirmation, resource ownership, and tenant isolation are
  unchanged.

## Migration

Import the `0.8.16` BOM and upgrade every AI Fabric artifact together.

For every planner-eligible READ action, declare the evidence domains represented
by that live read model:

```yaml
actions:
  - name: search_inventory
    accessMode: READ
    groundingEligible: true
    readActionResolutionEligible: true
    groundingVectorSpaces:
      - inventory-item
```

No indexed-data migration or reindex is required.

## Verification

- cross-domain read-action exclusion and matching-domain execution
- fair compound evidence packing with a decisive later-ranked document
- independent returned-document and used-document budgets
- truthful per-obligation usage diagnostics
- compound optimized-query isolation guidance
- complete core and curated-default regression suites

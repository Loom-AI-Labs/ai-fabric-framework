# AI Fabric `0.8.10`

- **Release date:** 2026-10-04
- **Maven group:** `io.github.loom-ai-labs`
- **Tag:** `ai-fabric-framework-v0.8.10`
- **Support policy:** latest release only; mixed or parallel framework/runtime versions are unsupported
- **Java:** 21
- **Spring Boot:** 4.1.x

AI Fabric `0.8.10` makes cross-turn target continuity intent-scoped. Conversation
history remains available to intent extraction, while persisted targets are
activated only after the extracted intent explicitly requires prior-target
resolution.

## Fixed

- Persisted action-result and attachment targets no longer enter orchestration
  context before intent extraction.
- Broad discovery turns no longer inherit hidden target scope from an earlier
  read action.
- Indirect follow-ups such as "of those" can still activate the bounded,
  server-owned target set after intent extraction.
- Request attachments remain authoritative and are never replaced by stored
  conversation targets.
- Expired, malformed, or future-dated persisted target metadata fails closed.
- The default intent prompt distinguishes indirect prior-item references from
  broad discovery and explicit item identifiers.

The implementation is action- and domain-neutral. It does not inspect action
names, target text, user wording, or application-specific fields.

## Migration

Consumers must upgrade the BOM and all AI Fabric artifacts together to
`0.8.10`. No compatibility mode or parallel old/new runtime is required.

Chat deployments using cross-turn target continuity should keep chat-session
pinned-target persistence enabled. Custom intent prompts must preserve the
`requiresTargetResolution` distinction: indirect references to prior results
set it to `true`; broad new discovery and explicit identifiers set it to
`false`.

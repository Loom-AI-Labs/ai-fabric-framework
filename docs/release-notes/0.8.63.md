# AI Fabric Framework 0.8.63

## Document Intelligence

- New optional `ai-fabric-document-readers` module: PDFBox PDF extraction,
  Apache POI DOCX/DOC extraction and replaceable image/scanned-PDF OCR.
- Local Tesseract adapter with server-owned executable/languages, bounded
  subprocess output, deadlines, temporary-file cleanup and no shell commands.
- Bounded file, archive, page, image-pixel and extracted-character allowances.
  Java parser deadlines are cooperative, not arbitrary-code hard termination.
- Stable page/section attribution and extraction diagnostics. Word embedded
  images are not OCR'd and Word page numbers are not invented.
- Existing Spring AI indexing now supports page-safe token overlap and explicit
  minimum chunk/indexed-text lengths without crossing section boundaries.
- Provider-neutral RAG evaluation contracts, numeric scored/unscored/failed
  outcomes and an adapter for existing Spring AI evaluators. Applications retain
  ownership, retrieval authorization, budgets, run storage and model selection.

This release does not upload documents, grant source visibility, create cloud
resources or automatically index/publish an application. Evaluation judgments
are diagnostics, not guarantees or authorization decisions.

See the document-readers README for usage and operating limits. Production
applications must qualify their own files, OCR languages, extraction quality,
retrieval, provider configuration and resource limits.

# AI Fabric `0.8.15`

- **Release date:** 2026-10-10
- **Maven group:** `io.github.loom-ai-labs`
- **Tag:** `ai-fabric-framework-v0.8.15`
- **Support policy:** latest release only; mixed or parallel framework/runtime versions are unsupported
- **Java:** 21
- **Spring Boot:** 4.1.x

AI Fabric `0.8.15` closes two ambiguity paths found while canarying compound
retrieval against a deployment with live-action and indexed knowledge sources.

## Added

- Grounding-eligible READ actions can declare `groundingVectorSpaces`. When an
  action returns successful but insufficient evidence, cooperative RAG can use
  this reviewed action contract instead of relying on an optional model field.
- The same contract is available through file-based connector catalogs and
  `@AIAction` annotations.
- Fallback diagnostics identify `INTENT`, `ACTION_CONTRACT`, or
  `ALLOWLIST_SINGLETON` as the selected evidence-scope source.

## Fixed

- `vectorSpaceSelectionRequired=true` now stops missing multi-domain selection
  before the heuristic router can silently broaden one information intent into
  fan-out retrieval.
- Knowledge-base prompt guidance no longer tells the model to omit a vector
  space when the active orchestration policy requires explicit selection.
- Action-contract fallback spaces remain subject to configured entity-type
  validation, deployment retrieval allowlists, and fan-out budgets.
- Model-selected fallback spaces are constrained by the action's reviewed
  `groundingVectorSpaces`; an out-of-contract model value cannot redirect the
  fallback to another allowed knowledge domain.

## Security And Compatibility

- `groundingVectorSpaces` is valid only for grounding-eligible READ actions.
  Connector catalogs fail startup when a write action attempts to declare it.
- The contract does not grant source access. Effective retrieval remains the
  intersection of valid framework routing and server-owned deployment policy.
- No browser or caller field gains retrieval authority.
- Write actions, confirmation, authorization, and tenant isolation are
  unchanged.

## Migration

Import the `0.8.15` BOM and upgrade every AI Fabric artifact together.

For a reviewed read action that may fall back to indexed evidence:

```yaml
actions:
  - name: search_inventory
    accessMode: READ
    groundingEligible: true
    groundingVectorSpaces:
      - inventory-item
```

For deployments where every retrieval intent must select one of several
approved domains, enable `vectorSpaceSelectionRequired` in the applicable
server-owned orchestration mode. If the model omits the selection, the request
fails closed with clarification instead of searching every allowed domain.

## Verification

- action-contract fallback after an insufficient direct READ result
- rejection of fallback-space metadata on non-READ actions
- action-contract routing provenance in diagnostics
- mandatory-selection behavior before heuristic fan-out
- focused core, connector, prompt, and metadata regression suites
- full framework, real-app, and empty-cache external-consumer release gates

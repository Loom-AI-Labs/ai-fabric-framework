# AI Fabric `0.8.25`

- **Release date:** 2026-10-11
- **Maven group:** `io.github.loom-ai-labs`
- **Tag:** `ai-fabric-framework-v0.8.25`
- **Support policy:** latest release only; mixed or parallel framework/runtime versions are unsupported
- **Java:** 21
- **Spring Boot:** 4.1.x

AI Fabric `0.8.25` strengthens progressive intent extraction so every semantic
stage is model-driven, provider-constrained, and validated against the trusted
deployment contract. It corrects the fallback path used when the primary
single-call extraction response is incomplete.

## Structured Progressive Extraction

- Classification now uses a closed provider-native JSON Schema requiring every
  semantic decision field for every intent, including obligation identity,
  retrieval, generation, target resolution, and advanced-RAG decisions.
- Action selection now uses a request-specific closed schema. The provider may
  return only an exact registered action identifier for the relevant intent or
  `null`; arbitrary prose cannot become an executable action.
- Parameter filling and read-action planning now advertise schemas for the
  payloads they actually parse instead of reusing the top-level intent schema.
- Deployment-owned system, intent-classification, and action-selection
  guidance is preserved when progressive extraction is used.
- Compound clauses are evaluated independently against both the registered
  action catalog and the exact knowledge-space catalog before an out-of-scope
  decision is made.
- An unresolved action selection remains unresolved and fails validation. The
  framework no longer promotes a free-form `actionHint` into an executable
  action identifier.

This correction adds no query keywords, phrase recognition, token-overlap
ranking, domain-specific routing, or hidden success fallback. The LLM remains
responsible for semantic decisions; deterministic code constrains output to
typed schemas, registered identifiers, authorization, and validation policy.

## Migration

Upgrade all AI Fabric artifacts through the `0.8.25` BOM. No database migration
or vector reindex is required. Deployments that supply managed prompts receive
the same guidance in both primary and progressive extraction paths.

## Verification

- focused schema, prompt-propagation, action-selection, planner, and
  fail-visible validation tests;
- real OpenAI progressive compound scenarios using provider-native strict
  schemas and committed vector evidence;
- complete framework reactor and restored integration-suite compilation;
- complete real-app reactor and all standalone consumer/application gates;
- Qdrant REST/gRPC, Weaviate, and Milvus container contracts;
- offline boot, ecommerce data-sync, specialist-chain restart, and deterministic
  scenario smokes; and
- semantic-decision source guard plus all framework release guards.

After publication, downstream consumers must run live-provider and deployment
canaries against the immutable Maven Central artifacts before production
promotion.

The relationship-query module is unchanged and remains outside this release's
correction claim.

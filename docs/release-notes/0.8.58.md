# AI Fabric 0.8.58

## Automatic Action Evidence

Connector actions now prepare answer evidence automatically when `llmFacts` is
absent. Only a successful action's approved `ActionPayload` is considered; the
projector does not read HTTP headers, upstream raw bodies, action parameters,
execution context or connection credentials. Nested objects and arbitrarily
named arrays are preserved instead of depending on documents/results/items keys.
Successful write receipts can supply actual result facts without repeating a write.
Failed payloads are not automatically forwarded.

Automatic preparation is bounded to six nesting levels, ten list items, 32 map
entries, 256 nodes and 12,000 serialized data characters, with a 2,000-character
leaf-text cap. Truncation is visible. Existing orchestration evidence budgets
still apply. Credential/transport field identifiers and declared sensitive
parameter field names are omitted recursively. This is not a classifier for
arbitrary confidential business data or secrets embedded in free text; producers
must retain their approved output contract and select narrower output as needed.

## Advanced Selected Fields

```yaml
llmFacts:
  mode: SELECTED_FIELDS
  lists:
    - sourcePath: products
      target: records
      maxItems: 8
      includeFields: [id, name, price]
```

Existing explicit `llmFacts` projections without `mode` remain selected-field
projections. An empty selected projection exposes no result data; it never falls
back to automatic preparation. Explicit `mode: AUTOMATIC` ignores any retained
selection rules, allowing editors to switch modes without erasing them. Invalid
operator modes fail configuration loading instead of silently expanding exposure.

Read-action evidence handling retains nested JSON within its bounded depth rather
than stringifying deep objects. No authorization, target ownership, confirmation,
model calls, retries, answer-breadth policy or document-source filters are relaxed.

Focused connector projection/catalogue, read planning and post-action generation
tests passed before release preparation (109 tests, zero failures/skips), including
arbitrary product arrays, nested values, empty selections, actual write receipts,
failed results, credential fields, bounded output and cycles. Publication/reactor

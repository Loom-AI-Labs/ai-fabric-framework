# AI Fabric `0.8.5`

- **Release date:** 2026-09-30
- **Maven group:** `io.github.loom-ai-labs`
- **Tag:** `ai-fabric-framework-v0.8.5`
- **Support policy:** latest release only; mixed or parallel framework/runtime versions are unsupported
- **Java:** 21
- **Spring Boot:** 4.1.x

AI Fabric `0.8.5` hardens model-planned read actions when optional action parameters are omitted as
JSON `null` values.

## Fixed

- Read-action planning now removes null parameter names and values before creating immutable action
  proposals.
- Valid non-null parameters from the same proposal continue to reach the registered action handler.
- Failure diagnostics use the same safe immutable parameter projection, preventing a secondary
  failure while reporting a rejected action.

This is a generic orchestration fix. It does not recognize application domains, action names, or
specific parameter fields. Application-owned schemas and handlers remain authoritative for whether
a non-null parameter is accepted.

## Security Boundary

- Null removal does not relax action eligibility, access mode, allowlists, authorization, trusted
  context, or governed execution checks.
- The framework does not synthesize missing parameters or convert untrusted values into trusted
  inputs.
- Required-parameter validation remains the responsibility of the action contract and handler.

## Migration

Consumers must upgrade the BOM and all AI Fabric artifacts together to `0.8.5`. No application code
or configuration change is required.

AI Fabric `0.8.5` is the only current contract and replaces earlier framework/runtime contracts.
There is no compatibility mode or parallel old/new runtime requirement.

## Verification

- A regression test proves a planner result containing both null and non-null optional parameters
  executes the selected read action with only the non-null parameter.
- Release completion requires the framework release guards, full Java 21 reactor, release-profile
  artifact build, Maven Central publication, and empty-cache external consumption.

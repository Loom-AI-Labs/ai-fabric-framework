# AI Fabric 0.8.46

This patch is based on immutable 0.8.45. Do not move or reuse its published tag.
Verify Maven Central availability before adopting 0.8.46.

## Scope

Remove deterministic generic-closer rewriting and correct managed generation
template composition. No database migration, vector reindexing, new provider,
or new runtime setting is introduced.

## Changes

- Response sanitization retains complete model-authored text, including closing
  sentences, questions, recommendations and handoffs. It no longer classifies
  sentences by phrases or strips terminal paragraphs. PII detection, forced
  redaction, sensitive-field filtering, warnings and sanitization events remain.
- Managed RAG answer/no-context and post-action user templates in the default,
  optimized-default, commerce and support bundles defer response breadth,
  permitted general knowledge, inference and next steps to the existing managed
  answer-generation and retrieval prompt slots. General advice and hypotheses
  must be distinguished from verified business facts. Live business facts,
  identity, authorization, attachment/reference rules and safety remain enforced.
- Managed post-action generation selects a managed system template rather than
  the unmanaged facts-only system template. Forced READ instructions and the
  READ-evidence wrapper retain business-fact authority while allowing explicitly
  configured, separately labeled general guidance. Style-only overlays still
  inherit grounded answer/retrieval defaults; user query wording does not select
  broader guidance. Generation controls, routing and fallback behavior are
  unchanged.
- `ManagedPromptDefaults` and unmanaged templates retain their existing grounded
  behavior. Broader guidance is not enabled by a new framework default.

## Consumer Notes

Remove these obsolete configuration properties and any calls to their generated
Java accessors:

- `ai.response-sanitization.remove-generic-assistance-closers`
- `ai.response-sanitization.generic-assistance-closer-prefixes`
- `ai.response-sanitization.generic-assistance-closer-fragments`

There is no replacement switch or compatibility alias. Use the existing managed
prompt slots for response guidance. Do not disable response sanitization or PII
redaction to change conversational style.

Keep framework modules aligned through the 0.8.46 BOM. The managed post-action
system template is packaged in `ai-fabric-curated-default`; do not combine a
0.8.46 core JAR with an older curated-default bundle.

The unrelated response-substitution and suggestions fallback paths are unchanged
by this patch. This release does not implement web research or claim perfect
semantic quality.

## Publication Gate

After applicable qualification and maintainer approval, commit the reviewed source,
recheck version availability, and create the immutable tag
`ai-fabric-framework-v0.8.46` at that exact commit. Push only the approved ref
and tag, then create a GitHub Release from the tag. The existing
`.github/workflows/maven-central-release.yml` workflow uses Java 21, pinned
Maven 3.9.16, signed source/Javadoc artifacts and the `release,central` profiles.
Publishing credentials remain in the existing workflow's secret configuration;
they are not required for local qualification or committed to this repository.

Publication success, clean Central-only consumption and application adoption
remain separate evidence gates. Source-classpath tests do not prove them.

# AI Fabric `0.8.14`

- **Release date:** 2026-10-09
- **Maven group:** `io.github.loom-ai-labs`
- **Tag:** `ai-fabric-framework-v0.8.14`
- **Support policy:** latest release only; mixed or parallel framework/runtime versions are unsupported
- **Java:** 21
- **Spring Boot:** 4.1.x

AI Fabric `0.8.14` completes the compound information-retrieval correction by
making read execution exact-once within a request and preserving each
information obligation through routing, fallback, and final synthesis.

## Fixed

- A request-local execution scope now deduplicates the same grounding-eligible
  read action with the same canonical parameter set across compound children.
  Diagnostics report suppressed duplicates and retain the original execution
  identifier when available.
- A successful but insufficient direct read action now contributes its bounded
  evidence to the cooperative RAG path without invoking the same action planner
  again. This prevents empty-result fallbacks from executing a read twice.
- Direct read-action fallback no longer broadens to every registered vector
  space. It uses the action intent's validated vector space or an unambiguous
  single-space server allowlist and otherwise leaves the original action result
  intact.
- Vector-space routing now evaluates each compound child's optimized query, so
  independent information obligations can select independent approved sources.
- The compound synthesis contract now requires the final answer to preserve
  exact requested terms, amounts, distances, conditions, requirements, and
  statuses present in collected evidence.
- Default compound extraction prompts preserve each independent clause and may
  assign a matching indexed fallback source to a read-action clause only from
  the trusted knowledge-base overview.

## Security And Compatibility

- Browser or caller context does not gain authority to register sources or
  broaden retrieval. Source selection remains bounded by deployment policy,
  the trusted knowledge-base overview, and server allowlists.
- Request-scoped deduplication applies only to read evidence collection. Write
  actions, confirmation, authorization, and execution policy are unchanged.
- The correction is domain-neutral. It contains no product, inventory,
  dealership, policy, or customer-specific matching rules.
- No database migration or new application configuration is required.

## Migration

Import the `0.8.14` BOM and upgrade every AI Fabric artifact together.
Applications overriding the default compound extraction or final-synthesis
prompts should merge the obligation-preservation rules described above.

## Verification

- request-scoped duplicate read-action suppression
- insufficient direct-action evidence retained during exact-source RAG fallback
- compound children routed with their own optimized queries
- final synthesis instructed to retain exact evidence terms
- generation-disabled and single-intent behavior preserved
- full core and curated prompt reactors plus public release guards

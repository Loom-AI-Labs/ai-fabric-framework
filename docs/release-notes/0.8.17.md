# AI Fabric `0.8.17`

- **Release date:** 2026-10-10
- **Maven group:** `io.github.loom-ai-labs`
- **Tag:** `ai-fabric-framework-v0.8.17`
- **Support policy:** latest release only; mixed or parallel framework/runtime versions are unsupported
- **Java:** 21
- **Spring Boot:** 4.1.x

AI Fabric `0.8.17` closes the remaining compound-evidence and conversational
target-continuity gaps discovered while canarying `0.8.16` against a hosted
multi-source deployment.

## Fixed

- Compound generation now ranks every authorized document for its own
  obligation before applying the global generation-document budget. A decisive
  later retrieval hit can no longer be discarded merely because less relevant
  hits appeared first.
- Query-relevant document ranking is repeated before the character budget is
  packed, while returned documents remain in provider order for client and
  audit visibility.
- Child `readActionResolution` diagnostics are aggregated at the compound
  result. Executed action IDs, grounding usability, empty action evidence, and
  RAG cooperation are no longer hidden inside child results.
- High-confidence ordinal and set references such as `of those` or `the second
  option` can recover bounded persisted targets when intent extraction misses
  `requiresTargetResolution`. The fallback requires conversation history,
  persisted targets, and an information intent; broad discovery requests do
  not activate stale targets.
- In multi-intent requests, only the clause carrying the structured target
  reference is marked target-dependent.
- A target-dependent information intent may derive its vector space from
  resolved targets only when every target has trusted provenance, every target
  agrees on one space, and that space is inside the server-owned retrieval
  policy. Mixed, missing, or disallowed target scopes keep the existing
  clarification/fallback behavior.

## Security And Compatibility

- Target context is a narrowing signal, never an access grant. It cannot add a
  vector space outside the deployment allowlist.
- The referential fallback contains no application-domain terms and does not
  reactivate persisted targets for ordinary standalone queries.
- Retrieval ranking operates only on documents already returned through
  authorized source, tenant, and deployment boundaries.
- Write actions, confirmation, ownership checks, and source isolation are
  unchanged.

## Migration

Import the `0.8.17` BOM and upgrade every AI Fabric artifact together. No
database migration, embedding migration, or reindex is required.

Applications projecting framework results should retain top-level compound
`readActionResolution` diagnostics and structured read actions when presenting
generated informational answers.

## Verification

- later-ranked decisive evidence under a two-document global generation budget
- exact compound read-action diagnostic aggregation and de-duplication
- structured referential fallback with broad-query and multi-intent negatives
- target-derived routing for agreeing, mixed, and disallowed target spaces
- complete core, chat-session, curated-pack, release-reactor, and real-app gates

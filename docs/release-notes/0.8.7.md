# AI Fabric `0.8.7`

- **Release date:** 2026-10-01
- **Maven group:** `io.github.loom-ai-labs`
- **Tag:** `ai-fabric-framework-v0.8.7`
- **Support policy:** latest release only; mixed or parallel framework/runtime versions are unsupported
- **Java:** 21
- **Spring Boot:** 4.1.x

AI Fabric `0.8.7` completes the grounding-sufficiency behavior introduced in
`0.8.6` for direct read-action intents.

## Fixed

- An allowlisted direct read action now honors `RAG_IF_ACTIONS_INSUFFICIENT`
  even when its conversation mode prefers actions.
- A successful action marked `groundingSufficiency=INSUFFICIENT` can no longer
  be projected as usable grounding or sent to post-action answer generation.
- An empty canonical `ActionListPayload` follows the same rule when no explicit
  sufficiency override is present.
- `groundingSufficiency=SUFFICIENT` remains the trusted way to declare that an
  authoritative empty result fully answers the request.
- Sanitized action diagnostics now retain the non-sensitive
  `groundingSufficiency` value for operational verification.

## Policy Boundary

The direct-action fallback is enabled only when the action is eligible under
the resolved server-owned read-action policy and that policy enables RAG
cooperation. Existing action-first modes without cooperative RAG retain their
current routing behavior.

The implementation uses normalized result contracts only. It does not inspect
action names, domain fields, query text, or generated answers.

## Migration

Consumers must upgrade the BOM and all AI Fabric artifacts together to `0.8.7`.
No compatibility mode or parallel old/new runtime is required.

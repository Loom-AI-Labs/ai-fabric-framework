# AI Fabric 0.8.50

## Scope

- A final INFORMATION direct-answer path no longer invents `Okay.` when the
  model supplied no answer. It returns `MODEL_DIRECT_ANSWER_MISSING` with
  `success=false`. Actual model-authored answers are not lexically rewritten.
  Missing direct text remains a warning during extraction because an authorized
  READ may still supply the answer before the final response is built.
- The READ planner can select an enabled, allowlisted, visible protected READ
  for authentication. Catalog entries distinguish `authenticationRequired` from
  `executableNow`. Its structured `REQUEST_AUTHENTICATION` decision, or selection
  of a protected READ for execution, returns the existing typed sign-in
  requirement before parameter binding or any protected invocation.
- Registered handlers, effective capability scope, native schemas, trusted
  identity bindings, anonymous execution checks and write confirmation remain
  mandatory. Public reads are not made private, and disallowed or unregistered
  tools do not become visible. No credentials are requested in chat.
- Safe response diagnostics include intent routing flags, direct-answer
  presence/source and the READ planner decision. They do not include raw model
  prompts, hidden reasoning or credentials.

No new recovery loop, keyword routing, automatic search-all or answer rewriting
is introduced. No migration, vector reindexing, endpoint or application auth
contract change is required. Consumers must use the consistent 0.8.50 BOM.

## Verification

Pre-publication qualification:

- Java 21 release-profile reactor: 2,413 tests passed, no failures/errors/skips;
  sources and Javadocs packaged. The final prompt clarifications were installed
  separately and the focused final source/prompt tests passed 77/77.
- All seven release guards and whitespace checks passed. Actual container
  contracts passed 8/8 plus 18 unit contracts (Qdrant REST/gRPC, Weaviate, Milvus).
- Real OpenAI `gpt-5.4-mini` native fixture: initial 8/9 tests passed, then 9/10
  after adding a direct real-planner component case and fuller diagnostics.
  The final run used twelve orchestration turns plus one planner call. Both
  anonymous private questions returned the existing auth requirement without
  receiver execution. The supplied-INFORMATION component test selected
  `REQUEST_AUTHENTICATION` through the real model, with zero receiver calls.
  Trusted nullable reads, collection, confirmed/rejected writes and the declared
  no-confirmation write passed.
- One strict public-guidance test remains failed: with indexed retrieval
  disabled, extraction authored "I can explain the cancellation process and
  billing timing." and the planner chose `ANSWER_FROM_CONTEXT` with no evidence
  read. The second policy variant performed its READ and passed. Prompt guidance
  clarifies that a candidate answer is not evidence, but does not make semantic
  correctness deterministic. This failure is retained, not relabelled, retried
  until green, converted to a synthetic answer or hidden by a keyword rule.
  The native suite is therefore **not all green**. The bounded auth/no-answer
  patch is qualified independently; remaining public-guidance quality is an
  explicit limitation under the owner's accepted LLM-error tolerance.

- General OpenAI/ONNX-384/Lucene core matrix: 11/11 inner cases passed, zero
  failures/skips/aborts; outer test 1/1. Normal 0.85/20 settings were retained;
  the existing harness clamps the effective minimum to its 11 available cases.
- Consuming application reports runtime 814/814 and control-plane compiler,
  capability-manifest and release-verification 75/75 tests passed on Java 21.

Central availability and empty-cache consumption are separate post-publication
gates. Live Platform/Engage qualification is owned by the consuming application,
with full query diagnostics retained. These results qualify the bounded patch,
not a blanket all-green framework or perfect model-answer quality claim.

The unrelated Incident Room baseline from 0.8.49 is not included in this patch
and must not be represented as fixed by these changes.

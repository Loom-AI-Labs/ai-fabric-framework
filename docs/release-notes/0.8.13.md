# AI Fabric `0.8.13`

- **Release date:** 2026-10-09
- **Maven group:** `io.github.loom-ai-labs`
- **Tag:** `ai-fabric-framework-v0.8.13`
- **Support policy:** latest release only; mixed or parallel framework/runtime versions are unsupported
- **Java:** 21
- **Spring Boot:** 4.1.x

AI Fabric `0.8.13` is a focused correction to the compound read-evidence flow
introduced in `0.8.12`. It prevents one clause in a compound request from
contaminating the read-action planning of another clause and strengthens the
default extraction contract for mixed action-and-information requests.

## Fixed

- Compound read-evidence handling now creates an internal, obligation-scoped
  effective query for each information child. Read-action planning and
  retrieval therefore operate on that child's extracted or optimized query,
  not on the full multi-clause request.
- The original user request remains unchanged for audit, request identity, and
  the single final synthesis. The scoped query is internal execution state and
  is not accepted from public request context.
- Ordinary single-intent planning continues to receive the complete effective
  user query. This preserves cases where an optimized query is lossy and the
  complete request is needed to select all relevant read actions.
- The default compound intent prompt now requires every independently
  answerable clause to be retained when clauses require different evidence
  paths.
- A request containing an available action clause and a separate knowledge
  clause must emit both an `ACTION` intent and an `INFORMATION` intent; the
  information clause may not be absorbed by the action.
- The correction is order-independent and domain-neutral. It does not contain
  dealership, inventory, policy, or product-specific matching rules.

## Security And Compatibility

- No write-action, confirmation, authorization, or public routing contract is
  relaxed.
- Only read-only, grounding-eligible compound collections receive the scoped
  child context. Compounds containing writes continue through their existing
  governed confirmation path.
- No browser-provided vector-space hint gains authority. Effective source and
  vector-space selection remains constrained by deployment policy and trusted
  server metadata.

## Migration

Consumers must upgrade the BOM and all AI Fabric artifacts together to
`0.8.13`. No configuration or database migration is required. Applications
that override the compound intent-extraction prompt should merge the new rule
that preserves independently answerable action and information clauses.

## Verification

- mixed action-plus-information extraction in every default compound prompt
  variant
- obligation-scoped read-action planner queries with the original request
  retained for audit
- single-intent full-query planning regression coverage
- two-information and read-action-plus-RAG compound synthesis coverage
- governed write and confirmation behavior unchanged
- full affected core and curated prompt reactor

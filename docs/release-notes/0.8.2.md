# AI Fabric `0.8.2`

- **Release date:** 2026-09-21
- **Maven group:** `io.github.loom-ai-labs`
- **Tag:** `ai-fabric-framework-v0.8.2`
- **Upgrade baseline:** `0.8.1`
- **Java:** 21
- **Spring Boot:** 4.1.x

AI Fabric `0.8.2` completes trusted-parameter continuity for governed actions confirmed through the
chat-session confirmation pipeline.

## Fixed

AI Fabric `0.8.1` persisted the names of action parameters resolved from trusted application
context. A remaining pipeline path could still lose those trust markers when the chat-session
module converted a positive confirmation into the restored action before core intent handling.

The confirmation pipeline now carries the pending action's trusted resolved-parameter names in
internal, request-scoped state keyed by normalized action name. Core action validation consumes
that state only for the matching action explicitly confirmed in the current request.

Configured and annotated confirmation interceptors preserve the same trust state when they execute
the pending action. Interceptors that execute a different action do not inherit the pending
action's trusted parameters.

## Security Boundary

- Trust originates only from a server-created `PendingAction` marker recorded during trusted
  context resolution.
- The request-scoped trust map is transient, excluded from JSON, and excluded from diagnostic
  string output.
- Trust is keyed by normalized action name and cannot flow to an unrelated action in a compound
  confirmation turn.
- Confirmation does not make arbitrary hidden or system-owned values trustworthy.
- A hidden value without the matching persisted marker still fails closed.
- No product, commerce, Shopify, or LoomAI-specific action name is present in the implementation.

## Compatibility

- No database migration or configuration change is required.
- No endpoint, action metadata, pending-action serialization, retrieval, indexing, specialist,
  chain, review, or document-ingestion contract changes.
- Applications can upgrade directly from `0.8.0` or `0.8.1`; the `0.8.0` document-indexing
  migration rules remain separate.
- Pending actions created before `0.8.1` without a trusted-resolution marker remain fail-closed and
  should be recreated from the original user request.

## Verification

- AI Fabric core: 685 tests pass with zero failures.
- AI Fabric chat-session: 60 tests pass with zero failures.
- Regression coverage proves single, compound, configured, and annotated confirmation paths carry
  only the matching pending action's trust markers.
- A paired negative regression continues to block unproven hidden pending parameters.

The release is complete only after the full framework reactor, release-profile artifact build,
external-consumer check, Maven Central publication, and a live two-turn consumer canary pass.

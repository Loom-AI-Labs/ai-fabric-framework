# AI Fabric `0.8.31`

- **Release date:** 2026-10-12
- **Maven group:** `io.github.loom-ai-labs`
- **Tag:** `ai-fabric-framework-v0.8.31`
- **Support policy:** latest release only; mixed or parallel framework/runtime versions are unsupported
- **Java:** 21
- **Spring Boot:** 4.1.x

AI Fabric `0.8.31` is a focused action-draft validation hardening release. It
ensures structured UI submissions and model-resolved draft continuations
cannot advance to confirmation unless their values satisfy the action's
declared `@Param` contract.

## Structured Draft Validation

- Structured `ActionDraftSubmission` values are validated before confirmation.
- Pattern, allowed-value, numeric bound, scalar type, object, array, nested
  required-property, and unknown-property constraints are enforced.
- Unknown or hidden top-level parameters are rejected.
- A rejected structured submission remains on the existing action draft and
  returns to parameter clarification without invoking the LLM or silently
  accepting malformed values.
- Model-resolved action-draft values pass through the same schema validator;
  malformed structured output is retried within the existing bounded call and
  cannot become a confirmation request.
- Final action invocation validation remains in place as a second independent
  boundary.

This is deterministic contract enforcement, not keyword routing. The LLM
continues to interpret user intent and conversational follow-ups; application
code remains authoritative for executable parameter contracts.

## Demonstration Hardening

The real-app suite now demonstrates the current orchestration contracts more
directly:

- Shopping combines grounding-eligible read actions with policy RAG, exposes
  cross-turn references and exact-once read diagnostics, and demonstrates
  cancellation retention interception.
- Account Resolver uses typed payment, address, and billing-resolution draft
  forms backed by the action schema.
- Incident Investigation Room declares runbook grounding domains and projects
  bounded planner rejection, repair, action execution, and evidence details.
- All deployable real-app Docker builds package with tests skipped; the full
  framework and real-app reactors remain the release test authority. This
  prevents runtime provider environment variables injected by a deployment
  platform from contaminating image-build tests.

## Migration

Adopt the `0.8.31` BOM consistently for all AI Fabric modules and rebuild the
application. No database migration, vector reindex, or configuration change is
required.

Applications that submit action-draft forms should send only fields declared
by public action parameter metadata. Previously tolerated malformed values may
now return to clarification instead of producing a confirmation card. That is
the intended behavior.

## Verification

- the existing shared action-contract validator covers patterns, allowed
  values, numeric bounds, nested unknown properties, and nested required
  properties at the newly connected draft boundary;
- structured draft tests prove invalid, hidden, unknown, and mismatched input
  cannot fall through to model extraction or confirmation;
- the complete AI Fabric core suite passes; and
- the complete deterministic real-app reactor remains the deployment gate.

The relationship-query module is unchanged and remains outside this release's
correction claim.

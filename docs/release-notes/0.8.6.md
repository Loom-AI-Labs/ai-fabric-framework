# AI Fabric `0.8.6`

- **Release date:** 2026-09-30
- **Maven group:** `io.github.loom-ai-labs`
- **Tag:** `ai-fabric-framework-v0.8.6`
- **Support policy:** latest release only; mixed or parallel framework/runtime versions are unsupported
- **Java:** 21
- **Spring Boot:** 4.1.x

AI Fabric `0.8.6` separates successful read-action execution from answer-grounding sufficiency.

## Fixed

- A successful empty typed `ActionListPayload` is now insufficient grounding by default.
- Under `RAG_IF_ACTIONS_INSUFFICIENT`, orchestration retains the empty action result as a no-match
  fact and invokes the configured retrieval fallback.
- Non-empty typed lists continue to ground answers without unnecessary retrieval.
- Typed list results now expose stable `items`, `itemsCount`, optional total/cursor values, and safe
  scalar extras to post-action generation without inventing a record for an empty list.

## Result Contract

Trusted action handlers and connectors may set `groundingSufficiency` to:

- `SUFFICIENT` when the result is authoritative and fully answers the requested fact, including an
  authoritative empty result; or
- `INSUFFICIENT` when successful execution still requires another configured grounding source.

Omitting the field uses typed-payload inference. Unknown connector values fail closed as
`INVALID_RESPONSE`. The framework does not inspect action names, domain fields, or answer text.

## Security Boundary

- Grounding sufficiency does not relax action eligibility, authorization, tenant/deployment scope,
  confirmation, trusted-context, or governed execution checks.
- The override is an action-owned result contract and must not be copied from model- or user-supplied
  input.
- Failed action execution remains a failure and cannot be promoted to sufficient grounding.

## Migration

Consumers must upgrade the BOM and all AI Fabric artifacts together to `0.8.6`. Connectors that
return collections should use the existing typed list wire contract (`_items` and `_count`). No
compatibility mode or parallel old/new runtime is required.

## Focused Verification

- `ReadActionResolutionServiceTest`
- `ActionResultSerializationTest`
- `ActionConnectorExecutorTest`
- `ConnectorAIActionHandlerTest`

These tests cover empty and non-empty typed lists, explicit trusted overrides, connector parsing,
invalid-value rejection, evidence retention, and post-action LLM fact projection.

# AI Fabric 0.8.44

## Scope

Focused READ-planning and evidence-handoff correction. No database migration,
vector reindexing, new semantic validator, lexical routing, or implicit retrieval
recovery is introduced. Existing action/source authorization and finite execution
bounds remain unchanged.

## Changes

- Approved structured READ evidence strings use the configured per-action
  evidence-character budget instead of an additional hidden 240-character cap.
  The final JSON context remains bounded, with existing item/depth guards.
  Applications should explicitly project approved JSON facts rather than pass
  arbitrary Java objects for string conversion.
- Conversation reference guidance tells planners and generators to preserve the
  originating user's issue order and subject. Tool questions and model-authored
  retrieval queries remain model decisions; there is no deterministic ordinal
  resolver or automatic semantic correction.
- Default and Support generation prompts distinguish authorized product help
  from undisclosed implementation details. Technical vocabulary alone no longer
  instructs these stages to suppress approved documentation.
- Generation guidance distinguishes optional features and conditional
  prerequisites from requirements for an entire product.
- The Support READ-planning overlay now includes the authorized knowledge-source
  catalogue, keeping its source-selection contract aligned with the default pack.

## Consumer Responsibilities

Keep application-owned projections, diagnostic consent, identities, and action
authorization. A completed execution is not proof of sufficient diagnostic
evidence. Clarification outcomes should preserve their message and declare
insufficient grounding when using the governed READ-action adapter.

For chain workers, align the output summary and manager-input schema with the
released bounded projection contract. Do not copy an unrestricted full answer
into a bounded summary or silently truncate it to conceal a contract mismatch.

## Verification

Focused source checks before publication: 114 tests passed across READ resolution,
conversation projection, RAG generation, chain execution/contracts, and
Default/Support/Commerce curated prompts, with no skips. Release guards passed.
Release guards and publication/consumer results are recorded separately in the
release evidence. Real-provider product quality is measured on the deployed
consumer; deterministic tests do not establish a universal answer-quality claim.

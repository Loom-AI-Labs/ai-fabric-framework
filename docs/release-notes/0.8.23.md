# AI Fabric `0.8.23`

- **Release date:** 2026-10-11
- **Maven group:** `io.github.loom-ai-labs`
- **Tag:** `ai-fabric-framework-v0.8.23`
- **Support policy:** latest release only; mixed or parallel framework/runtime versions are unsupported
- **Java:** 21
- **Spring Boot:** 4.1.x

AI Fabric `0.8.23` corrects the provider output envelope used by structured
intent extraction. The semantic-decision, validation, and explicit recovery
contracts introduced in `0.8.22` are unchanged.

## Structured Intent Provider Contract

- Intent extraction now selects schema-guided JSON-object mode before the
  provider call.
- The complete intent schema remains available to prompt construction and
  framework validation.
- Closed output contracts may still opt into provider-native strict JSON
  Schema mode.
- Dynamic application-owned maps such as action parameters and response
  metadata are no longer submitted as an OpenAI strict schema that cannot
  represent their valid keys.
- OpenAI and Gemini adapters honor the declared JSON-object mode instead of
  silently promoting the request back to native strict-schema mode.

This is a declared request contract, not a provider-error retry. The framework
does not infer intent from text, synthesize a successful fallback, or bypass
the bounded model-repair and typed-failure policy.

## Migration

Upgrade all AI Fabric artifacts through the `0.8.23` BOM. No database migration
or vector reindex is required. Deployments using `0.8.22` with OpenAI
orchestration should upgrade because strict native schema validation can reject
the dynamic intent contract before model execution.

# AI Fabric 0.8.60

## Respect Context-Only Plans With Selected Inputs

A completed READ planner decision of `ANSWER_FROM_CONTEXT`, together with
`requiresRetrieval=false`, no proposed actions and no further planning steps,
can use available current attachments, normalized attachments, transient input,
resolved targets or pinned context as well as approved conversation history.
Their presence no longer forces cooperative RAG merely because no new READ
action executed. A first question with an attachment does not need an earlier
conversation turn to qualify.

Existing ownership checks, retrieval/source authorization, action access,
confirmation and call budgets are unchanged. User-provided context does not
become verified server data or fresh business evidence. Incomplete plans,
rejected action proposals, failed/insufficient READ results and explicit RAG
decisions retain their existing handling. No keyword routing, default namespace,
extra model call, forced fan-out or semantic replacement is introduced.

Diagnostics include the kinds of available context input without logging their
payloads. Existing `contextOnlyContinuation`, planner and branch diagnostics
remain available. Automatic/Selected action evidence preparation is unchanged;
this patch does not restore a raw-result fallback.

## Qualification

Focused regression tests cover five current-input forms without history, two
resolved results with history, conversation ownership mismatch, explicit
retrieval requests and failed/insufficient READ handling. Publication, complete
release-reactor results and hosted adoption must be reported from completed
verification, not inferred from this release note.

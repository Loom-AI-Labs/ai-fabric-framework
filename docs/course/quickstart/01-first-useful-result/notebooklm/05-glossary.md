# Glossary

**AI Fabric**: Java framework contracts and orchestration used by the application.

**Application domain record**: Source-of-truth business data owned by application services.

**Embedding**: Numeric representation of text used for similarity comparison.

**ONNX**: Local model runtime used in this lesson to create embeddings without cloud credentials.

**Lucene vector index**: Local vector storage and similarity-search implementation used in this
lesson.

**Metadata**: Stable identity and contextual fields stored with a vector for filtering and evidence
display.

**Semantic search**: Retrieval by vector similarity rather than exact keyword equality.

**Evidence**: Retrieved content and source identity returned by the search contract.

**RAG**: Retrieval-augmented generation. It is introduced later; QS-01 proves retrieval only.

# QS-01 NotebookLM Lesson Brief

## Purpose

Create a 3-5 minute pre-lesson architecture explanation titled **From Application Record To Semantic
Evidence** for Java and Spring Boot developers who have not used AI Fabric.

This is theory orientation, not a code-along. The learner should finish able to explain why a database
row is not vector evidence and trace one semantic-search request end to end.

## Required Topics

1. Semantic similarity versus keyword matching and general model knowledge.
2. Application record -> approved content/metadata -> ONNX embedding -> Lucene vector.
3. Query -> query embedding -> similarity search -> evidence response.
4. Application, AI Fabric, provider, vector store, and browser ownership.
5. Honest no-evidence behavior before indexing.
6. What the future executable lab will prove.

## Prohibited Claims

- Do not describe this preview as an executed learner lab.
- Do not claim the NotebookLM video is already published.
- Do not invent performance, accuracy, compliance, or production-readiness numbers.
- Do not describe database records as indexed evidence.
- Do not imply a language model is required for semantic retrieval.

## Lab Handoff

End by asking the learner to predict the result of searching after seed but before index, then proceed
to the lesson and knowledge check.
